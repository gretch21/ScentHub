# ScentHub

ScentHub is a perfume shop app for managing products and inventory, recording sales, and viewing revenue and top sellers. It is built with React Native (Expo), TypeScript, and SQLite.

> Built with AI coding tools. I defined the features, directed the AI, tested the app, and fixed errors.

## Features

- Add, edit, and manage perfume products and stock
- Record sales
- View total revenue and top-selling products
- Owner, Staff, and Cashier accounts with different access

## Tech stack

- React Native with Expo
- TypeScript
- SQLite (data stored on the device)

## How to run

1. Install [Node.js](https://nodejs.org/).
2. In this folder, run `npm install`.
3. Run `npx expo start`, then open the app in Expo Go or an emulator.

## Known limitations

- This is a school demo. Passwords are stored as plain text in the local database, and a default Owner account is created on first run. Do not use it as-is for a real business.
- Data stays on the device; there is no server or online backup.
